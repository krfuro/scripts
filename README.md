# Scripts – krfuro

Samling av automatiseringsscripts for praktiske oppgaver.

## Innhold

| Mappe | Beskrivelse |
|-------|-------------|
| `angermann/` | Last ned lærebøker fra angerman.no som PDF |
| `lomholan-fagbokforlaget/` | Last ned ressursfiler fra lomholan.fagbokforlaget.no |
